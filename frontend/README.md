# frontend

Vue 3 + TypeScript single-page app (search/filter UI, results, company and alumni detail views). Talks to the `backend` REST API.

Planned scaffold (via [Vite](https://vitejs.dev/)):

```
frontend/
├── package.json
├── tsconfig.json
├── vite.config.ts
├── index.html
└── src/
    ├── main.ts
    ├── App.vue
    ├── components/
    ├── views/
    └── api/            # typed client for the backend REST API
```

Not yet scaffolded — see the root [README.md](../README.md) for overall architecture.
